# Controle de Peso

Aplicativo web da Agropecuária Paineira para pesagem e venda de animais.

Fluxo: **Pesagem → Valores → Vendedor → Comprador → Relatório**.

Recursos atuais:
- vários animais por operação;
- brinco, peso e descrição;
- valor por kg;
- Fundo Rural padrão de 1,5% e editável;
- peso total e médio, valor bruto e líquido;
- dados do vendedor e comprador;
- busca de cidade e endereço pelo CEP;
- e-mail do vendedor opcional;
- voltar, cancelar, excluir animal e imprimir;
- relatório preparado para A4 retrato;
- dados temporários salvos no navegador via localStorage.

Para publicar, habilite o GitHub Pages usando a branch `main` e a pasta `/ (root)`.
